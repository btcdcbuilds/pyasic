# Layout rules

Values marked `TBD` are set by our licensed engineer and the ops lead. Until
set, layouts **report** the measured gaps but must not say "OK" or "compliant".

| Check | Minimum | Set by | Notes |
|-------|---------|--------|-------|
| Unit to property boundary | TBD m | Engineer | Local setback rules vary by area and building type; the customer must check with their local district office (อบต./เทศบาล/สำนักงานเขต) |
| Unit to unit (side by side) | TBD m | Engineer | Maintenance access + fire separation |
| Unit to existing building | TBD m | Engineer | |
| AC outdoor unit clearance | TBD m | AC installer | From the AC maker's install manual |
| Truck/crane access path width | TBD m | Ops lead | Measured from the customer's photos of the road and gate |
| Crane reach from truck position to unit centre | TBD m | Ops lead | Depends on the hired crane truck |
| Overhead power lines near the lift path | Always flag to a human | Ops lead | Never approve automatically |
| Ground slope | Flag if visible slope or customer reports slope | Engineer | Piles can level some slope: engineer decides |

## Always escalate to a human (CTO Fred)

- Stacked / 2-storey layouts
- More than 6 units on one site
- Sites with slopes, water, soft ground, or within the flagged distance of power lines
- Any request for permit drawings
