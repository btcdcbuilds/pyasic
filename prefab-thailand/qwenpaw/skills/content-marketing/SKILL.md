# Content & Marketing

Use `brand-voice-sales` for voice and `prefab-catalog` for facts. Prices come
only from `back-office`.

## Weekly calendar (draft every Friday)

| Pillar | Example |
|--------|---------|
| How-to advice | Foundations (why screw piles), AC sizing for a unit, heat insulation, site office checklist |
| Real installs | Only real jobs, with customer permission; never stock photos presented as our work |
| Cost breakdowns | Built from the price list; dated |
| Staff accommodation | Layouts, stacking (engineer-approved info only) |
| Behind the scenes | Container arrival, QC checks, unfolding time-lapse |

## Ads

| Rule | Detail |
|------|--------|
| Drafts only | Owner approves every new ad and any budget change |
| Claims | Only facts in the catalogue or backed by documents. Never "no permit needed", never unverified fire/wind ratings, never "in stock" before stock has landed |
| Targeting | Construction business owners/engineers/project managers (EEC + Bangkok); data-centre EPC contractors; factory HR/admin (staff accommodation); homeowners 28–55 (home office, rental room, farm); website retargeting |

## Platform rules

| Do | Don't |
|----|-------|
| Post as the brand Page; join groups as the Page where admins allow it | Create fake personal profiles or pretend to be a customer |
| Answer questions helpfully in groups | Post the same message into many groups |
| Use official APIs/schedulers | Use browser automation to post, join groups or fake engagement |

## Research (browser_use: read only)

- Competitor list: name, channel, sizes, price range, lead time, install offered, reviews → `research/competitors.csv`
- Construction / data-centre / factory projects near our area → leads list for `sales-support`, with source links
- Never log in to other people's accounts or scrape personal data
