## 2. The brand character

Make **one transparent, branded expert persona** instead of fake personal
profiles. It works better long term and keeps every account safe.

| Element | Plan |
|---------|------|
| Name | e.g. "Khun [Name] from [BRAND]" (a mascot/illustrated character, not a fake real person) |
| Personality | Practical site-engineer type: friendly, straight-talking, knows foundations, electrics, permits, sizing, heat insulation |
| Disclosure | Bio and first message say it's [BRAND]'s AI assistant, with a human team behind it. Required to stay within Meta's rules ([Meta: inauthentic behaviour](https://transparency.meta.com/en-gb/policies/community-standards/inauthentic-behavior/)) and protects us under consumer law |
| Voice | Thai first, English second, Chinese for suppliers; casual-polite (ครับ/ค่ะ set by the persona) |
| Content pillars | 1) How-to (foundations, AC sizing, permits) 2) Real installs 3) Cost breakdowns 4) Site-office checklists 5) Staff-accommodation standards |
| Where it posts | Our Page, our LINE OA timeline (VOOM), our TikTok/YouTube, our website blog. In Facebook groups, **as the Page** where group admins allow Pages, following each group's rules |

### Facebook groups: what's allowed vs not

| ✅ Do | ❌ Don't |
|------|---------|
| Join groups as the brand Page where allowed | Create fake personal profiles run by AI |
| Answer questions helpfully and link to guides only when relevant | Spam the same post into many groups (Meta specifically targets this) |
| Ask admins for permission / sponsor a group | Use computer-use bots to mass-join groups or fake engagement |
| Have a human team member post personally under their real name, with AI drafting help | Pretend to be an unrelated customer recommending us |

**Computer-use automation:** use it for internal tasks only (research,
competitor price checks, filling our own supplier/marketplace back-office forms
where no API exists), not for posing as people on social platforms.

## 3. Paid ads (targeted)

| Campaign | Platform | Audience | Offer |
|----------|----------|----------|-------|
| Site offices | Meta + Google Search | Construction business owners, engineers, project managers; EEC + Bangkok geos | "In stock — delivered & installed on screw piles in X days" (only once stock has landed) |
| Staff accommodation | LinkedIn + Google | HR/admin managers, factory owners, contractors | Cost-per-bed calculator on the website |
| Homeowners | Meta + TikTok + Lazada | Homeowners 28–55, home office, rental income, farm | Show-unit visit + financing info (if available) |
| Data centre | LinkedIn + direct | EPC contractors, project directors | Documentation pack (drawings, specs, certificates) |
| Retargeting | Meta + Google | Website visitors, configurator users | Quote reminder, show-unit tour video |

**Ad rules for the ads agent:**

| Rule | Detail |
|------|--------|
| Budget | Daily caps set by the owner; agent can rebalance between ad sets but **cannot raise the total** |
| Claims | Only claims in the approved claims list (e.g. no "no permit needed", no unverified fire ratings) |
| Creative | AI-drafted, human-approved before going live |
| Reporting | Weekly: spend, leads, cost per lead, quotes, sales, cost per sale, by channel |

## 5. Pre-selling the first container

| Tactic | How |
|--------|-----|
| Reservation deposits | Refundable or partly refundable deposit to reserve a unit from the first container, with an "arrival price" discount. Terms set by the lawyer |
| Launch list | LINE OA + WhatsApp broadcast list from the ads (with PDPA-compliant consent) |
| B2B letters of intent | Contractors / data-centre EPCs sign non-binding LOIs for X units |
| Show unit early | If affordable, ship the sample unit ahead (LCL / flat-rack) so content can start before the full container lands (get a freight quote first) |
